# Prospective 845-item bank: demand-led unit coverage matrix

**Scope and method.** The prospective snapshot contains 845 questions, 845 manifest entries, 845 unique question IDs, and all 38 units in `/private/tmp/patternly-claude-expansion-20261007/units.json`. I verified exact canonical-object SHA-256 matches for all 845 manifest rows. The existing curriculum was read at `patternly-content/config/curricula/claude-certified-architect-professional-certification.json`; its 38 block/target plans and each unit’s actual objective provide the scope. This is a coverage/adequacy judgment, not per-item acceptance: candidate C/B questions still need their independent whole-object reviews. The matrix uses question objects (prompt, keyed action and feedback rationale) as evidence; prior author ledgers are context, not proof. Supporting IDs below are exact representative items, not a claim that every item in each unit has passed.

Counts emerge from the number and consequence of decision families and their evidence/boundary variants. They are not quotas, exam weights, or minimums. I considered whether a changed fact changes the decision, whether learners see a consequential novice error, whether both sides of a boundary are practiced where the unit needs them, and whether different evidence/workflow representations are present. Similar items count as practice when a different stage, evidence state, authority boundary, workload, or outcome changes the reasoning. No additional mechanism is required solely to justify an item.
